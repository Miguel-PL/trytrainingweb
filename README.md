# trytraining-frontend

Frontend desarrollado con Vue.js para una aplicación de gestión de entrenamientos deportivos para gimnasio.

La aplicación permite visualizar y administrar rutinas de entrenamiento mediante una interfaz web conectada a una API REST desarrollada en Laravel.

## Características

* Visualización de entrenamientos
* Gestión de rutinas
* Comunicación con APIs REST
* Interfaz orientada a pantallas de gimnasio
* Navegación dinámica con Vue.js

## Tecnologías utilizadas

* Vue.js
* JavaScript
* HTML
* CSS
* Axios

## Instalación

```bash
git clone <url-del-repositorio>
cd gym-workouts-frontend
npm install
```

## Ejecutar proyecto

```bash
npm run dev
```
